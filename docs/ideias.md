# CoreRouter — ideias (fora da lista de gaps)

Melhorias que a pesquisa de uma feature encontrou (como outro roteador faz, uma RFC opcional, um
extra de operação) e que **ninguém pediu ainda**. Não são trabalho comprometido, não entram na
contagem de gaps abertas e nenhuma sessão as pega sozinha. Uma ideia vira gap quando o usuário ou
a sessão principal a escolhe: a sessão que for fazê-la registra a gap no `docs/changes/<id>.md`
dela, citando a ideia daqui (G0.34).

Gerado pela fila de entrada: a seção `## ideias` do `docs/changes/<id>.md` de cada PR entra aqui,
no fim, quando ele é integrado (`cargo xtask docs fold`). **Não edite à mão**, exceto para apagar
uma ideia que virou gap ou que não faz mais sentido.

Formato de cada item: `- **Título curto**: o que é, de onde veio (fonte, link) e por que
ajudaria.`
