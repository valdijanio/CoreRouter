id: G0.26

Correção do `cargo xtask vm-lab tools`. Quando só faltavam pacotes apt (o `iperf3`), o script mandava uma lista de hashes vazia ao `sha256sum -c`, que falha ("no properly formatted checksum lines found", **medido**). Agora o script é montado por `vm_tools::install_script` (com testes): o `sha256sum` só entra quando há `.deb`, e os hashes vão por heredoc. `snapshot`, `reset` e `tools` também aceitam rodar dentro do `flock vm/root.lock` do próprio usuário: a trava de um processo ancestral conta como dele. O `status` mostra se a VM está ociosa ("rounds"). Testar: `cargo xtask vm-lab status` e `cargo xtask vm-lab tools --check`.
