history: G0.26 criado e feito (laboratório em VM com root para agentes)

Laboratório em VM com root para agentes: `cargo xtask vm-lab <create|up|down|status|ssh|sync|put|run|snapshot|reset|destroy>` (`xtask/src/vm_lab.rs`, `docs/vm-lab.md`). A VM `corerouter-lab` (libvirt `qemu:///system`, sem `sudo` no host) sobe de uma imagem Ubuntu 24.04 cloud baixada uma vez e conferida com o `SHA256SUMS` publicado, com overlay qcow2 fino de 20 GiB, 8 vCPUs e 8 GiB, kernel HWE 7.0, pacotes de teste (clang, llvm, tcpdump, ppp, pppoe, ethtool, nftables…) e rustup em `/opt/rust`. Gerência na rede `default` NAT que já existia; enlaces de teste são pares de NICs virtio ligados por UDP no loopback do host (`wire0a` ↔ `wire0b`), sem bridge nem iptables novos. `run -- <cmd>` copia a worktree (rsync, sem `target*`/`.git`) e roda como root com cache de build por worktree. Testar: `cargo xtask vm-lab create`, depois `cargo xtask vm-lab run -- env COREROUTER_REQUIRE_XDP=1 cargo xtask xdp-root`. Validado: os 13 testes do `xdp-root` passam na VM; `auto` vira `native` no `virtio_net` (`ip.firewall.xdp.interface.list` com `active: native`, `ip link` mostra `xdp`). Achado: o kernel 6.8 (Ubuntu 24.04 GA) recusa o programa XDP no verificador ("combined stack size of 3 calls is 544. Too large", **medido**); a VM usa o HWE 7.0.
